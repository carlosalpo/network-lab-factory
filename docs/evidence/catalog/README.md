# Recorded catalog evidence

Recorded on October 29, 2026. These are observations from isolated EVE-NG Professional 7.2.0-4 and GNS3 3.0.6 installations, not a live service or a certification of all images.

The 48 reference records cover one implemented variant of each of 24 cases on both backends. Five GNS3 practice samples are included separately. Reference success requires preparation and exercise checks to pass; practice leaves the exercise pending. Fault/recovery and a Nexus automatic restart have separate records.

This public export keeps the original command observations and removes transport addresses, local filesystem locations, identifiers, console ports and connection records. Each deployment record includes the SHA256 of its unmodified local source result. This is traceability, not an independent attestation. Failed attempts remain in the private campaign archive; these files are the final successful observations, not a claim that every attempt succeeded.

The laboratories were powered off and deleted after validation. See [cleanup.json](cleanup.json). UI captures use fixture inventory and are labeled separately; they are not substitutes for these network results.
