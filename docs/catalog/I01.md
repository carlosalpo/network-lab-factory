# I01 · Campus de tres capas

Construir una maqueta de campus y comprender acceso, distribución y núcleo.

## Variante implementada

Topología fija: 7 equipos y 9 enlaces. Recursos EVE: 5 vCPU y 5136 MiB; GNS3: 7 vCPU y 5184 MiB; se exige 1024 MiB de margen adicional y disco libre antes de crear.

```text
                             ///[core01]\\\\
              ///////////////               \\\\\\\\\\\\\\\
  [dist01]\\\\---------------------------------------------///[dist02]
      |       \\\\\\\\\\\\\\\               ///////////////       |
      |                      \\\\\\\\\\\\\\\                      |
      |       ///////////////               \\\\\\\\\\\\\\\       |
   [acc01]////                                             \\\\[acc02]
      |                                                           |
      |                                                           |
    [h01]                                                       [h02]
```

## Preparación y ejercicio

**Preparación automática:** Acceso, distribución y núcleo conectados; VLAN y direccionamiento base preparados.

**Ejercicio:** Configurar OSPF entre distribución y núcleo; las VLAN y gateways ya están preparados.

Práctica aplica la base y comprueba su estado; referencia aplica también la solución y exige que las comprobaciones del ejercicio pasen.

## Direccionamiento y conexiones

Pools predeterminados: tránsito `10.240.0.0/16` dividido en /30; loopbacks `10.241.0.0/16` asignadas como /32; LAN `10.242.0.0/16` dividida en /24. El asistente propone un pool de loopbacks /24, suficiente para estas variantes. Son editables, privados y no se superponen.

```text
core01 GigabitEthernet0/0 -- dist01 GigabitEthernet0/0
  10.240.0.0/30
core01 GigabitEthernet0/1 -- dist02 GigabitEthernet0/0
  10.240.0.4/30
dist01 GigabitEthernet0/1 -- dist02 GigabitEthernet0/1
  10.240.0.8/30
acc01 GigabitEthernet0/0 -- dist01 GigabitEthernet0/2
acc01 GigabitEthernet0/1 -- dist02 GigabitEthernet0/2
acc02 GigabitEthernet0/0 -- dist01 GigabitEthernet0/3
acc02 GigabitEthernet0/1 -- dist02 GigabitEthernet0/3
h01 eth0 -- acc01 GigabitEthernet0/2
h02 eth0 -- acc02 GigabitEthernet0/2

DIRECCIONES
core01: GigabitEthernet0/0 10.240.0.1/30, GigabitEthernet0/1 10.240.0.5/30, Loopback0 10.241.0.1/32
dist01: GigabitEthernet0/0 10.240.0.2/30, GigabitEthernet0/1 10.240.0.9/30, Loopback0 10.241.0.2/32, Vlan100 10.242.0.1/24
dist02: GigabitEthernet0/0 10.240.0.6/30, GigabitEthernet0/1 10.240.0.10/30, Loopback0 10.241.0.3/32, Vlan101 10.242.1.1/24
h01: eth0 10.242.0.10/24
h02: eth0 10.242.1.10/24
```

VLAN, áreas, ASN, identificadores VRF y VNI son valores definidos por la receta; se incluyen en la configuración exportada. IPv6 utiliza el prefijo de laboratorio `fd42:4e4c:4600::/48`. No se reservan direcciones fuera de esta maqueta aislada.

## Límites

La cantidad de equipos y la estructura son las de esta variante. No incluye todas las variantes pedagógicas posibles del escenario. Las pruebas son funcionales; no miden rendimiento ni tiempo de convergencia.

EVE: laboratorio nuevo en la carpeta elegida, tenant admin 0, sin enlaces externos. No se sobrescriben laboratorios. Una falla conserva el registro y los recursos creados para inspección; no se reintenta automáticamente.

GNS3: proyecto nuevo mediante el perfil 3.0.6 Nexo; acceso SSH directo o sesión temporal de Proxmox. No agrega enlaces externos ni instala imágenes. Si falta una imagen o su BIOS, la creación se detiene antes de crear recursos.

La preparación completa, la solución y las pruebas se exportan con `nlf plan I01 --name ejemplo-i01 --mode reference --output build/ejemplo-i01`.
